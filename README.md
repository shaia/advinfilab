# אינפי מתקדם 1 — ספר לימוד חי

קורס אינטראקטיבי בעברית ללימוד עצמי של חשבון אינפיניטסימלי מתקדם, ברמה של שנה ב באוניברסיטה, לפי הסילבוס של הקורס
**80315 "חשבון אינפיניטסימלי מתקדם (1)"** באוניברסיטה העברית (דף הקורס של רות לורנס-נוימרק, תשס"א): מרחבים מטריים
ונורמיים, קומפקטיות ושלמות, המרחב C(K) ומשפט הקירוב של ויירשטראס, פונקציות ℝᵐ → ℝⁿ (דיפרנציאביליות, כלל השרשרת,
טיילור וההסיאן, משפטי הפונקציה ההפוכה והסתומה, כופלי לגרנז'), אינטגרלים קוויים, ואינטגרל רימן בכמה משתנים (משפט לבג,
פוביני, החלפת משתנים). לפניו פרק 0 שמרענן את מה שהקורס מניח מאינפי 1–2 ומאלגברה לינארית. (טורי פורייה ומשוואות דיפרנציאליות,
שבסילבוס העדכני של השנתון, הועברו לקורס אינפי מתקדם 2.)

לכל פרק יש מסלול מדורג: **שאלות הבנה** לכל שיעור (בסיס, בינוני, מבחן), **שאלות חזרה** על כל הפרק, **שאלות מבחן**
עם הוכחה מלאה, מחוון להערכה עצמית, ו**מבחן פרק** מוגרל עם דוח.

הקורס בנוי על הפלטפורמה של קורסי האחות "חשמל ומגנטיות" (emlab), "אופטיקה" (optlab) ו"אינפי 1" (infilab): Astro 7,
Preact, MDX ו-KaTeX, בעיצוב של "ספר חי".

**מצב:** הפלטפורמה מוכנה, מפת הקורס (10 פרקים, 60 שיעורים, 184 מטרות) ובנקי השאלות של כל הפרקים כתובים (שלב 0).
